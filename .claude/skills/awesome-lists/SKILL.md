## How to use

1. Find the matching list(s): `grep -n -i "<topic>" references/awesome.md`
   (e.g. video, ffmpeg, seo, react, n8n, scraping, design, youtube, marketing, ai).
2. Each entry links to a GitHub repo holding the actual curated list. Fetch that list's
   README (raw.githubusercontent.com/<owner>/<repo>/HEAD/readme.md, or clone it with
   `git clone --depth 1`) and read only the relevant section.
3. Shortlist 2-5 options; check each candidate's GitHub activity (last commit, stars,
   license) before recommending or installing it.
4. For a newer copy of the index:
   https://raw.githubusercontent.com/sindresorhus/awesome/main/readme.md
